Marketing Profesional

Prompt maestro para tu logo profesional

Un prompt largo y detallado — vale la pena, porque controla proporciones, geometría y estilo como lo haría un diseñador. Complétalo y pégalo en tu IA favorita.

✅ Contenido desbloqueado

1 Completa los datos

Antes de copiar, reemplaza mentalmente cada casilla amarilla con los datos de tu negocio: nombre, rubro, colores, estilo y los valores que quieres transmitir.

2 El prompt

Diseña una identidad visual profesional y altamente coherente para:

NOMBRE DEL NEGOCIO: [NOMBRE DEL NEGOCIO]
RUBRO / INDUSTRIA: [RUBRO O INDUSTRIA]
SERVICIO PRINCIPAL: [SERVICIO PRINCIPAL]
PÚBLICO OBJETIVO: [PÚBLICO OBJETIVO]

1. Identidad de marca

La identidad debe transmitir principalmente: [VALOR 1], [VALOR 2] y [VALOR 3].

La personalidad de la marca debe ser: [MODERNA / PROFESIONAL / PREMIUM / CERCANA / ROBUSTA / ELEGANTE / INNOVADORA].

2. Concepto visual

Crear un símbolo gráfico basado en UNA SOLA IDEA VISUAL PRINCIPAL.

ELEMENTO PRINCIPAL: [UN SOLO OBJETO, FORMA O CONCEPTO RELACIONADO CON EL NEGOCIO]
RECURSO SECUNDARIO OPCIONAL: [UN SOLO ELEMENTO SECUNDARIO O "NINGUNO"]

Utilizar únicamente 1 elemento visual principal + 1 recurso secundario como máximo. No intentar representar todos los elementos relacionados con el rubro. El símbolo debe comunicar el negocio mediante síntesis visual, no mediante una ilustración literal. No combinar múltiples objetos independientes.

3. Construcción del símbolo

Crear un símbolo compacto basado en una silueta principal única, clara y reconocible. Construirlo mediante formas geométricas simples, curvas limpias, proporciones controladas, alineaciones precisas y espacios negativos intencionales. El símbolo debe parecer construido profesionalmente en software vectorial. Debe tener:

  • Geometría limpia
  • Proporciones equilibradas
  • Curvas suaves
  • Grosor visual consistente
  • Bordes definidos
  • Espacios negativos controlados
  • Pocos elementos
  • Una silueta reconocible incluso a tamaño pequeño

4. Simplificación

Aplicar un nivel de simplificación propio de una identidad corporativa profesional. Eliminar cualquier elemento que no sea necesario para comunicar el concepto. Priorizar: SILUETA > PROPORCIÓN > GEOMETRÍA > RECONOCIMIENTO > DETALLE. Si un detalle no mejora la identificación del símbolo, eliminarlo. El resultado debe poder describirse visualmente con una frase corta.

5. Geometría y proporciones

Todas las partes del símbolo deben utilizar el mismo lenguaje geométrico. Mantener:

  • Grosor visual uniforme
  • Radios de curva coherentes
  • Esquinas consistentes
  • Proporciones equilibradas
  • Alineaciones precisas
  • Espaciado uniforme
  • Simetría cuando corresponda

Las curvas deben ser suaves y continuas. Las intersecciones deben ser limpias. No crear deformaciones, uniones extrañas, elementos flotantes ni formas accidentalmente fusionadas.

6. Espacio negativo

Utilizar espacio negativo únicamente cuando tenga una función visual o conceptual clara. Los espacios internos deben ser amplios, limpios e intencionales. Evitar pequeños huecos, perforaciones innecesarias, detalles microscópicos y espacios accidentales.

7. Estilo visual

Estilo: [MINIMALISTA / MODERNO / PREMIUM / CORPORATIVO / ELEGANTE / ROBUSTO / TECNOLÓGICO / AMIGABLE]

El resultado debe ser limpio, profesional, contemporáneo, memorable, escalable y atemporal. Debe funcionar como una verdadera identidad de marca y no como un clipart o ilustración genérica.

8. Color

COLOR PRINCIPAL: [COLOR 1]
COLOR SECUNDARIO: [COLOR 2]
COLOR DE DESTACADOS Y CONTORNOS: NEGRO PURO #000000

Utilizar colores planos, sólidos y de alto contraste. El negro puro debe utilizarse en los elementos destacados, contornos o detalles estructurales que necesiten mayor contraste. No utilizar degradados, transparencias, sombras, brillos ni efectos de iluminación. El diseño debe funcionar correctamente en color, negro sobre blanco, blanco sobre negro y una sola tinta.

9. Texto

TIPO DE LOGO: [SOLO SÍMBOLO / SÍMBOLO + NOMBRE / ISOTIPO / ISOLOGO]

Si incluye texto — NOMBRE: [NOMBRE DEL NEGOCIO], SUBTÍTULO: [SUBTÍTULO / NINGUNO]. Utilizar una tipografía [MODERNA / GEOMÉTRICA / ELEGANTE / ROBUSTA / MINIMALISTA], perfectamente legible y coherente con el símbolo. No deformar las letras. No utilizar tipografías excesivamente decorativas.

10. Composición

DISTRIBUCIÓN: [VERTICAL / HORIZONTAL / AMBAS]

Mantener una relación proporcional clara entre símbolo y texto. El símbolo debe conservar una presencia visual fuerte sin competir excesivamente con el nombre. Mantener suficiente espacio libre alrededor de todos los elementos.

11. Calidad vectorial

El resultado debe tener apariencia de diseño vectorial profesional, con bordes perfectamente definidos, curvas suaves, formas limpias, geometría precisa, proporciones consistentes, ausencia de artefactos y ausencia de deformaciones. Debe ser fácil de convertir posteriormente a SVG, EPS o PDF vectorial.

12. Restricciones absolutas

NO utilizar: sombras, degradados, brillos, efectos 3D, biseles, texturas, perspectiva, efectos metálicos, volumen artificial, fotorealismo, mockups, fotografías, escenarios, ni elementos decorativos innecesarios o exceso de detalles.

NO agregar objetos que no hayan sido definidos en el concepto. NO combinar múltiples símbolos independientes. NO deformar herramientas, objetos, letras o elementos gráficos. NO crear intersecciones confusas. NO agregar detalles simplemente para hacer el logo más llamativo.

La simplicidad, limpieza y coherencia visual tienen prioridad absoluta sobre el detalle.

13. Prueba final de calidad

Antes de finalizar, comprobar:

  • ¿Existe una sola idea visual dominante?
  • ¿La silueta se entiende inmediatamente?
  • ¿El símbolo funciona sin texto?
  • ¿Funciona en blanco y negro?
  • ¿Se reconoce a tamaño pequeño?
  • ¿Las proporciones son coherentes?
  • ¿Todas las formas utilizan el mismo lenguaje geométrico?
  • ¿Existe algún elemento innecesario?
  • ¿Hay alguna intersección confusa?
  • ¿Parece realmente un logotipo profesional?

Si existe algún elemento innecesario, eliminarlo. Si existen demasiados detalles, simplificarlo. Si dos elementos compiten visualmente, priorizar uno.

Resultado final

Generar un logotipo profesional, limpio, geométricamente coherente, minimalista, memorable y fácilmente reconocible. El resultado debe parecer diseñado por un especialista en branding e identidad visual, preparado para convertirse posteriormente en un archivo vectorial profesional.

PRIORIDAD ABSOLUTA: 1. Silueta limpia — 2. Concepto único — 3. Proporciones — 4. Geometría — 5. Reconocimiento — 6. Simplicidad — 7. Identidad de marca. No priorizar el detalle sobre la claridad.
