# PROMPT MAESTRO — LOGOTIPO PROFESIONAL

Actúa como un director de arte y diseñador de identidades visuales de primer nivel, especializado en creación de marcas modernas, minimalistas, geométricas y profesionalmente construidas.

Tu tarea es desarrollar un logotipo limpio, distintivo, minimalista y visualmente memorable, basado en una síntesis geométrica clara y una construcción visual precisa.

DATOS EDITABLES — CAMBIA SOLO LO AMARILLO

Completa estos datos antes de copiar el prompt

Negocio: [NOMBRE]

Rubro / industria: [INDUSTRIA]

Servicio principal: [SERVICIO]

Público objetivo: [PÚBLICO]

Valores clave: [VALOR 1, VALOR 2, VALOR 3]

Concepto visual principal: [CONCEPTO / OBJETO]

Color 1: [COLOR 1]

Color 2: [COLOR 2]

Formato de entrega: [SOLO ISOTIPO / ISOTIPO + NOMBRE]

Importante: Los datos de arriba son las únicas variables que debes cambiar. El resto del prompt debe mantenerse igual.

REGLAS DE DISEÑO

1. CONCEPTO ÚNICO

Construye el símbolo alrededor de un único concepto visual principal: el concepto visual principal indicado en los datos editables.

El concepto debe estar sintetizado y simplificado geométricamente, evitando una representación literal o ilustrativa.

Puede utilizarse máximo 1 elemento secundario, únicamente cuando esté integrado de manera natural en el concepto principal y mejore su lectura.

El resultado debe tener un único foco visual dominante.

2. SÍNTESIS Y GEOMETRÍA

Construye el símbolo mediante:

  • formas geométricas simples
  • proporciones equilibradas
  • curvas limpias
  • ángulos coherentes
  • espacios negativos intencionales
  • grosor visual consistente
  • simetría o asimetría deliberada
  • pocos elementos
  • alta síntesis visual

El símbolo debe parecer construido geométricamente, con precisión de diseño profesional.

Evita detalles pequeños que puedan perderse al reducir el logotipo.

3. CALIDAD DE SILUETA

La silueta debe ser fuerte, reconocible y memorable.

Debe funcionar correctamente:

  • a tamaño grande
  • a tamaño pequeño
  • en una sola tinta
  • completamente en negro
  • independientemente del color

El símbolo debe conservar su identidad cuando se elimina el color.

La forma debe poder reconocerse únicamente por su silueta y estructura geométrica.

4. RESTRICCIONES VISUALES

El diseño debe ser estrictamente:

2D + plano + limpio + minimalista + geométrico.

Utiliza únicamente formas sólidas y una construcción visual clara.

El fondo debe ser:

blanco sólido puro (#FFFFFF).

No introducir efectos visuales que alteren la construcción plana del símbolo.

5. PALETA

Utiliza como máximo:

  • el Color 1 indicado en los datos editables
  • el Color 2 indicado en los datos editables
  • negro puro (#000000) cuando sea necesario para contraste estructural.

Los colores deben ser planos, sólidos y uniformes.

No introducir colores adicionales.

6. TIPOGRAFÍA Y FORMATO DE ENTREGA

Respeta estrictamente la variable:

Formato de entrega: el formato de entrega indicado en los datos editables

Si se especifica:

SOLO ISOTIPO

→ generar exclusivamente el símbolo.
→ no incluir nombre, palabra, letras, iniciales ni texto adicional.

Si se especifica:

ISOTIPO + NOMBRE

→ generar el símbolo acompañado del nombre exacto:

el nombre indicado en los datos editables

Utilizar una tipografía sans-serif geométrica, moderna, limpia y profesional.

La tipografía debe complementar el símbolo, mantener una jerarquía clara y presentar un espaciado equilibrado.

Nunca inventar, modificar o sustituir el nombre proporcionado.

7. LIMPIEZA Y PRECISIÓN

El resultado debe sentirse como un logotipo profesional diseñado por un estudio de branding, no como una ilustración.

Cada forma, corte, curva y espacio negativo debe tener una función visual.

Prioriza:

simplicidad → precisión → reconocimiento → memorabilidad.

La solución debe ser visualmente limpia incluso cuando se observa a tamaño reducido.

PROCESO DE EJECUCIÓN

PASO 1 — SÍNTESIS GEOMÉTRICA

Antes de generar la imagen, ESCRIBE EN EL CHAT ÚNICAMENTE 2 LÍNEAS:

Línea 1: describe la síntesis geométrica que utilizarás para transformar el concepto visual principal indicado en los datos editables en un símbolo.

Línea 2: valida brevemente que la solución cumple la prueba de silueta simple, reconocimiento, escalabilidad y ausencia de elementos superfluos.

No escribas ninguna explicación adicional en este paso.

Inmediatamente después de escribir esas 2 líneas, ejecuta la generación de la imagen.

PASO 2 — GENERACIÓN

Genera el logotipo aplicando estrictamente la síntesis geométrica definida en el Paso 1.

Respeta todas las variables proporcionadas:

  • concepto
  • formato de entrega
  • nombre
  • colores
  • geometría
  • composición
  • estilo visual

No modificar el concepto durante la generación.

La composición final debe ser limpia, equilibrada, centrada y presentada sobre fondo blanco puro.

INSTRUCCIÓN DE TRADUCCIÓN PARA LA HERRAMIENTA VISUAL

Si necesitas generar un prompt interno para una herramienta de imagen, redacta la descripción exclusivamente en términos positivos, describiendo únicamente las formas, características, composición, colores, geometría y elementos que deben estar presentes.

No traduzcas las restricciones como negaciones ni describas elementos ausentes.

Prioriza siempre una descripción positiva de la solución visual final.

CRITERIO FINAL

El resultado debe parecer un isotipo profesional, geométrico, minimalista y listo para convertirse en una identidad de marca, con una construcción visual simple, memorable, reproducible y fácilmente vectorizable.

La calidad debe provenir de la síntesis y precisión del diseño, no de la cantidad de elementos.
